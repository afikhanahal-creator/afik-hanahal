# סטודיו הווידאו של אפיק הנחל (OpenMontage + Claude Code)

החבילה הזו הופכת את Claude Code במחשב שלכם לאולפן הפקה לסרטוני נדל״ן, בסגנון של אפיק הנחל.

## מה יש כאן

| קובץ | מה הוא עושה |
|---|---|
| `install-openmontage.ps1` | מתקין הכל: Python, Node.js ו-FFmpeg (אם חסרים), את החבילות של OpenMontage, ומוסיף את הסגנון וההנחיות שלנו |
| `styles/afik-hanahal.yaml` | סגנון המותג: הצבעים של האתר, הגופן Rubik, כתוביות בעברית מימין לשמאל, תנועה רגועה ויוקרתית |
| `skills/creative/real-estate-afik.md` | ההנחיות לסרטוני נדל״ן: מבנה של רילס (פתיח, חללים, פרטים, כרטיס נתונים, מיקום, סיום), אמת בכל מספר, "הדמיה" על כל חומר AI, טלפון וקישור לקביעת שיחה בסוף |

## התקנה (פעם אחת)

1. חלצו את הקובץ לכל תיקייה.
2. בתיקייה שחולצה: קליק ימני ← "פתח ב-Terminal" (או PowerShell) ← הריצו:
   ```
   powershell -ExecutionPolicy Bypass -File .\install-openmontage.ps1 -Root "C:\Users\HP\Desktop\Downloads\OpenMontage-main"
   ```
3. אם הסקריפט התקין Python / Node / FFmpeg בפעם הראשונה ואומר שהוא לא רואה אותם, סגרו את החלון, פתחו חדש והריצו שוב.

## עבודה יומיומית

1. במערכת באתר: **סטודיו וידאו** ← בוחרים נכס ואיך הסרטון ייראה ← **העתקת ההוראה**.
2. ב-PowerShell:
   ```
   cd "C:\Users\HP\Desktop\Downloads\OpenMontage-main"; claude
   ```
3. מדביקים את ההוראה ושולחים. Claude יציג תסריט, סטוריבורד ועלות לפני הרינדור.
4. לוח ההפקה (לראות את ההתקדמות, גם מתוך הטאב במערכת):
   ```
   .\.venv\Scripts\python -m backlot open
   ```

## מפתחות API (לא חובה)

בלי מפתחות זה עובד בחינם: התמונות והצילומים של הנכס, מוזיקה וכתוביות.
ליצירת תמונות / וידאו / קול ב-AI: פותחים את הקובץ `.env` בתיקיית OpenMontage ב-Notepad ומדביקים שם את המפתח
(למשל `FAL_KEY=...`, `ELEVENLABS_API_KEY=...`). **אף פעם לא בצ׳אט ולא באתר.**

OpenMontage הוא קוד פתוח (רישיון AGPLv3) ורץ רק אצלכם במחשב.
